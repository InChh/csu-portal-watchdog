# CSU Portal Watchdog

用 Rust 编写的中南大学校园网自动认证 CLI。Windows 计划任务每 5 分钟检查外网，确认终端认证离线后尝试一次 HTTPS Portal 登录。仓库附带 Windows x64 EXE，使用者无需安装 Python 或 Rust。

## 前置要求

- **Windows 10/11 x64**：凭据存储使用 Windows DPAPI，定时运行使用 Windows 任务计划程序。
- **校园网接入与账号**：电脑已连接中南大学校园网，能够访问 `portal.csu.edu.cn` 的 HTTPS 服务及 802 端口，并持有可用的校园网账号和密码。目前仅支持已核对的有线接入环境、`login_method=1`；无线接入或需要选择运营商的环境尚未验证。
- **本机目录与任务权限**：下载或 clone 完整仓库，放在当前 Windows 用户可写的固定目录；当前用户需要有创建计划任务的权限，系统任务计划程序服务需可用。安装后请保留目录位置，否则计划任务无法找到程序。
- **使用同一 Windows 用户**：首次配置和后续运行使用同一 Windows 用户。任务仅在该用户登录 Windows 时运行，关机或退出 Windows 登录期间不会运行。

直接使用仓库中的 EXE，无需安装 Python、Rust 或第三方包。

## 使用

1. 确认满足上述前置要求。
2. 下载或 clone 完整仓库，保存在固定目录。
3. 双击 `setup.cmd`，在本机输入校园网账号和密码。

同目录的 `csu-portal-watchdog.exe` 用于配置、手动操作和计划任务运行，允许显示控制台窗口。

首次配置后后台任务自动运行。密码通过当前 Windows 用户的 DPAPI 加密保存，后续无需手动输入；修改密码时重新运行 `setup.cmd`。

接口参数、运行方式、日志位置和停用命令见 [使用说明](使用说明.md)。当前实现支持已确认的有线接入环境、`login_method=1`，其他接入点的运营商选择或认证协议需要另外核对。

## 认证条件

外网检测失败后会复测；认证首页和状态接口都明确表示离线，才准备登录。提交前再次检查认证状态、终端地址和外网。已经在线或无法确认状态时跳过认证。登录后用实际外网响应验证恢复结果。

程序没有登出、注销、解绑或强制其他终端下线请求，也不重置网卡或修改 DNS、代理。

## 验证

以下命令仅供源码开发者使用，需要 Windows 原生 Rust 工具链；普通使用者无需运行。

```bash
cargo test --locked
```

测试覆盖在线跳过、状态不确定、瞬时网络恢复、地址变化、单次认证、禁止跟随重定向、DPAPI 凭据存储和五分钟计划任务定义。测试使用虚构账号及文档示例 IP，不提交真实校园网认证请求。

## 从源码构建 EXE

仅构建者需要 Windows 原生 Rust MSVC 工具链和 Visual Studio C++ 构建工具：

```bash
cargo build --release --locked
cp target/release/csu-portal-watchdog.exe .
```

构建输出位于被 Git 忽略的 `target/`。程序目录、账号、终端地址和 Windows 用户标识均在本机配置或运行时取得。

## 本机数据

`state/` 保存加密凭据、日志和计划任务信息，已加入 `.gitignore`。这些运行文件留在本机；仓库包含 Rust 源码、EXE 和文档。日志不会记录密码、完整登录 URL 或原始认证响应。
