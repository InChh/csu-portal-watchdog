# CSU Portal Watchdog

中南大学校园网自动认证脚本。Windows 计划任务每 5 分钟检查外网，确认终端认证离线后尝试一次 HTTPS Portal 登录。使用 Python 标准库，无需第三方依赖。

## 使用

1. 安装 Windows 原生 Python 3.10 或更高版本。
2. 下载仓库文件，保存在固定目录。
3. 双击 `setup.cmd`，在本机输入校园网账号和密码。

首次配置后后台任务自动运行。密码通过当前 Windows 用户的 DPAPI 加密保存，后续无需手动输入；修改密码时重新运行 `setup.cmd`。

接口参数、运行方式、日志位置和停用命令见 [使用说明](使用说明.md)。当前实现支持已确认的有线接入环境、`login_method=1`，其他接入点的运营商选择或认证协议需要另外核对。

## 认证条件

外网检测失败后会复测；认证首页和状态接口都明确表示离线，才准备登录。提交前再次检查认证状态、终端地址和外网。已经在线或无法确认状态时跳过认证。登录后用实际外网响应验证恢复结果。

脚本没有登出、注销、解绑或强制其他终端下线请求，也不重置网卡或修改 DNS、代理。

## 验证

```bash
python -B -X utf8 -m unittest discover -s tests -v
```

测试覆盖在线跳过、状态不确定、瞬时网络恢复、地址变化、单次认证、禁止跟随重定向、DPAPI 凭据存储和五分钟计划任务定义。测试使用虚构账号及文档示例 IP，不提交真实校园网认证请求。

实机检查已验证在线探测、认证参数读取和系统计划任务 XML 兼容性；真实断网后的认证恢复尚未实测。

## 本机数据

`state/` 保存加密凭据、日志和计划任务信息，已加入 `.gitignore`。这些运行文件留在本机；仓库只包含脚本、文档和测试。日志不会记录密码、完整登录 URL 或原始认证响应。
